# aiiron

Coach IA multisport et santé, en français, dans WhatsApp. Voir `CLAUDE.md` pour la vision, les principes et l'équipe d'agents.

## Démarrer avec Claude Code
1. Ouvrir ce repo dans Claude Code (web, desktop ou terminal) et accepter de faire confiance au dossier.
2. Installer les plugins déclarés dans `.claude/settings.json` (voir `/plugin`).
3. Optionnel : définir `HEVY_API_KEY` dans ton environnement pour le serveur MCP Hevy (`.mcp.json`).
