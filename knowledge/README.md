# Bases de connaissances

Rédigées par les sous-agents experts, au format du skill `fiche-connaissance`. Statut `brouillon` tant que Pierrot ne les a pas validées.

| Dossier | Contenu | Propriétaire |
| --- | --- | --- |
| `force/` | RPE, %1RM, e1RM, périodisation, peaking | expert-force |
| `hypertrophie/` | Volume, fréquence, échec, sélection, `mapping-muscles.json` | expert-hypertrophie |
| `course/` | Zones, plans, trail, sprint, conditionnement | expert-course |
| `nutrition/` | Énergie, macros, timing, compléments, garde-fous | expert-nutrition |
| `sante-physique/` | Prévention, douleur, récupération, sommeil, wearables | expert-sante-physique |
| `echauffement/` `mobilite/` `etirements/` | Protocoles et routines | expert-sante-physique |
| `sante-mentale/` | Motivation, stress, **protocole de crise** | expert-sante-mentale |
| `modeles/` | Modèles de semaines par discipline, base de la mécanique « semaine type → programme » | experts concernés |
