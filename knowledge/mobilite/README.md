# Mobilité : modules et routines

Propriétaire : `expert-sante-physique`. Statut de toutes les fiches : `brouillon`. Format machine : voir `knowledge/echauffement/README.md`.

| Fiche | Contenu |
| --- | --- |
| `mobilite-modules.md` | Briques par articulation (cheville, hanche, charnière, colonne thoracique, épaule, poignet), en version dynamique (avant séance) et autonome (après séance ou jour de repos) |
| `mobilite-force.md` | Mobilité avant et après une séance de force, par mouvement principal |
| `mobilite-musculation.md` | Mobilité avant et après une séance de musculation, par région (haut, bas, full) |
| `mobilite-course.md` | Mobilité avant une séance de course intense et routine d'après |
| `mobilite-hyrox-crossfit.md` | Mobilité globale avant et après une séance Hyrox ou CrossFit |

Les fiches par type de séance n'inventent pas d'exercices : elles assemblent des modules de `mobilite-modules.md`. Pour changer un dosage, on modifie le module.
